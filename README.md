## Read evidence precisely

| Dimension | What it describes |
|---|---|
| Publication | Technical report, preprint, submission, acceptance or publication |
| Implementation | Model, experimental artifact, release candidate or maintained release |
| Evaluation | Author-run checks, external artifact evaluation or independent reproduction |

These dimensions are not interchangeable. A proof under stated assumptions does not certify a complete deployment. Negative results and reproducibility discrepancies are welcome.

Maintained software belongs in its technical repository. Scientific records link to the exact source commit or artifact version used for the result; later corrections remain traceable.

<details>
<summary>Before proposing a record</summary>

Use the [record template](RECORD_TEMPLATE.md). Confirm authorship, redistribution rights, publication approval and the artifact license. Do not upload an unpublished manuscript merely because its title appears elsewhere.

Identify assumptions, non-claims, environment, commands, expected results and checks not run. Add a citation file only when the authorship and citation target are known.

</details>
