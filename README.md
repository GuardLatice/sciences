# GuardLatice Sciences

Research on secure computation, cryptography, access governance and distributed systems.

**[Explore the scientific portal](https://sciences.guardlatice.com/)** · [Publication method](PUBLICATION.md) · [Report a correction](https://github.com/GuardLatice/sciences/issues)

This repository is the scientific entry point on GitHub. It records approved publications, reproducible artifacts, corrections and independent reproduction reports. Maintained software belongs in its technical repository and is linked by exact version.

The GitHub catalog is being established. An empty catalog means no record has yet been approved for this repository; it does not mean no GuardLatice research exists. Manuscripts and artifacts are not automatically copied from private working directories.

## Read evidence precisely

Publication status, implementation maturity and independent evaluation are separate. A proof under stated assumptions is not certification of a complete deployment. Negative results and reproducibility discrepancies are welcome.

Use the [record template](RECORD_TEMPLATE.md) for a proposed entry. Submit only material you are authorized to publish. Each artifact needs its own license and exact version.
