# GuardLatice Sciences

Research in cryptography, access governance, secure computation and distributed systems.

**[Visit the scientific portal](https://sciences.guardlatice.com/)** · [Publication policy](PUBLICATION.md) · [Report a correction](https://github.com/GuardLatice/sciences/issues)

## Explore the work

Use the scientific portal to learn about the research program. For questions or a possible collaboration, [start a research discussion](https://github.com/GuardLatice/.github/discussions/new?category=research) with a topic you can share publicly.

The [GitHub catalog](catalog.json) has no publication entries yet. This repository currently provides publication guidance; it does not distribute manuscripts, research code or publication files.

## Corrections and contributions

A useful correction identifies the public work, the section involved and the reasoning or observation to examine. Negative results and disagreements are welcome when they are specific and reproducible.

Publication status, implementation maturity and independent evaluation are recorded separately. A result proved under assumptions is not a certification of an entire system.
